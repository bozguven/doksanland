# Doksanland

Fully automated Turkish viral-culture magazine for Instagram (@doksanland).
A newsroom of AI desks (trend, humor, nostalgia, screen, everyday life, curated reposts, design, video,
rights gate, analytics) fills a calendar; Bertuğ approves; GitHub Actions publishes through Meta's Graph API.

- Brief: [clients/doksanland/brief.md](clients/doksanland/brief.md)
